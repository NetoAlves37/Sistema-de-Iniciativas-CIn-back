## Teste de integração do critério do calendário

O critério "iniciativas não aprovadas não aparecem no calendário" depende de SQL
(`WHERE s.code = 'APROVADA'`) e não é testável em nível unitário. Ele é coberto por
`test/integration/iniciativas/calendario-somente-aprovadas.int-spec.ts`, rodado à parte contra
o banco de testes recriado:

```bash
node scripts/prepare-database.mjs BD-SICIN-TEST --reset
npx vitest run --config vitest.integration.config.ts test/integration/iniciativas/calendario-somente-aprovadas.int-spec.ts
```

Resultado: 1 / 1 passando. Saída em
[`saida-terminal-integracao-calendario.txt`](saida-terminal-integracao-calendario.txt).
Esse teste conta para a cobertura de requisitos, mas **não** entra nos percentuais de linhas e
branches acima, para manter a comparação com a v1 no mesmo escopo e com a mesma ferramenta.
